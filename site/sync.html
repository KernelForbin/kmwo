Health sync

An iPhone Shortcut sends your steps and weigh-ins from Apple Health to kmwo every morning. (Shortcuts can’t read workouts, so add those from the day page.)

1 · Sync key

The Shortcut uses this key to add data to your log. It can’t read anything. It’s shown once; making a new one stops the old one working.

Copy it into the Shortcut now. It won’t be shown again.

2 · Build the Shortcut

In the Shortcuts app, tap + and name it kmwo sync. Add these actions in order. To use a property like Start Date, tap the Repeat Item variable and pick it from the list.

  1. Steps. Find Health Samples: Type Steps, filter Start Date is in the last 10 days, Group By None. (Raw samples, so kmwo can remove the iPhone + Watch double count the way Health does.)
  2. Repeat with Each item in Health Samples. Inside it:
    • Format Date: Repeat Item › Start Date, Date Format Custom yyyy-MM-dd HH:mm:ss
    • A second Format Date: Repeat Item › End Date, same custom format
    • Text: Start|End|Value|Source (the first Formatted Date, |, the second Formatted Date, |, Repeat Item › Value, |, Repeat Item › Source)
  3. After End Repeat: Combine Text Repeat Results with New Lines, then Set Variable Steps.
  4. Weight. Find Health Samples: Type Weight, Start Date in the last 365 days, no Group By. Repeat with Each: Format Date Start Date as yyyy-MM-dd, then Text Formatted Date|Value. Combine Text with New Lines, Set Variable Weights. (A year, so weigh-ins from your scale app fill in your history.)
  5. Get Contents of URL:
    Method POST. Headers: apikey =
    and Content-Type = application/json. Request Body JSON, three Text fields: p_key = your sync key, p_steps = Steps, p_weights = Weights.
  6. Optional: Show Notification with Contents of URL, to see what synced.

Run it once by hand. Allow it to read Health and to connect to supabase.co. The top of this page should then show the sync.

3 · Run it every morning

  1. Shortcuts › Automation › + › Alarm › Is Stopped (or Charger › Is Disconnected).
  2. Choose Run Immediately, then pick kmwo sync.

iPhone only lets Shortcuts read Health while the phone is unlocked, so a morning trigger works better than a set time overnight. Each run re-sends the last 10 days, so a missed morning catches up later.

Good to know

  • Synced steps and weigh-ins replace that day’s values.
  • Steps from your iPhone and Apple Watch are combined the way Health does it, so they aren’t counted twice.
  • The oldest day in each sync is left alone, since a “last 10 days” window starts partway through it.
