Apple Health

Health sync

An iPhone Shortcut sends your steps and weigh-ins from Apple Health to kmwo every morning. (Shortcuts can’t read workouts, so add those from the day page.)

1 · Sync key

The Shortcut uses this key to add data to your log. It can’t read anything. It’s shown once; making a new one stops the old one working.

Copy it into the Shortcut now. It won’t be shown again.

2 · Build the Shortcut

In the Shortcuts app, tap + and name it kmwo sync. Add these actions in order.

Anything highlighted below, like Start Date or Formatted Date, must be a coloured variable tag, not typed text. Tap the field, pick the variable from the bar above the keyboard (or Select Variable), then tap the tag to choose a property such as Start Date, Value or Source. Typed words stay white and are sent as-is.

  1. Steps. Find Health Samples: Type Steps, filter Start Date is in the last 10 days, Group By None. Group By Day adds iPhone and Watch steps together; raw samples let kmwo count them the way Health does.
  2. Repeat with Each item in Health Samples. Inside it:
    • Format Date: Repeat Item › Start Date, Date Format Custom yyyy-MM-dd HH:mm:ss.
    • A second Format Date: Repeat Item › End Date, same custom format.
    • Text: four tags with a typed | between them: Formatted Date (start) | Formatted Date (end) | Repeat Item › Value | Repeat Item › Source. To tell the two dates apart, tap one and choose Rename (e.g. Start, End).
  3. After End Repeat: Combine Text Repeat Results with New Lines, then Set Variable Steps. A line should look like 2026-11-10 07:15:00|2026-11-10 07:22:41|612|Apple Watch. To check, add Quick Look here for one run.
  4. Weight. Find Health Samples: Type Weight, Start Date in the last 365 days, Group By None. Repeat with Each: Format Date Start Date as custom yyyy-MM-dd, then Text: Formatted Date | Repeat Item › Value. After End Repeat: Combine Text with New Lines, Set Variable Weights.
  5. Get Contents of URL, with this URL:
    Method POST. Two headers:
    • apikey = this public key (starts sb_publishable_):
    • Content-Type = application/json
    Request Body JSON, three Text fields:
    • p_key = your sync key from step 1 (not the public key)
    • p_steps = the Steps variable
    • p_weights = the Weights variable
  6. Show Notification with Contents of URL, so each run shows what synced.

Run it once by hand. Allow it to read Health and to connect to supabase.co. A good result looks like {"ok":true,"step_samples":830,"steps_days":10,"weigh_ins":1,…}, and the top of this page shows the sync.

Or let Shortcuts build it from a description

If your Shortcuts app offers to build a shortcut from a description, paste this, then replace the three PASTE_ placeholders using the copy buttons above. Check the result against the steps above: it often sets Group By to Day or types variable names as plain text.

Create a shortcut named "kmwo sync" that does the following:

1. Find Health Samples where Type is Steps and Start Date is in the last 10 days. Do not group the results (Group By: None). Sort by Start Date, oldest first.

2. Repeat with each item in those step samples:
   a. Format Date: the Repeat Item's Start Date, custom format yyyy-MM-dd HH:mm:ss. Name this "Start".
   b. Format Date: the Repeat Item's End Date, custom format yyyy-MM-dd HH:mm:ss. Name this "End".
   c. Text: the Start variable, a | character, the End variable, a | character, the Repeat Item's Value, a | character, the Repeat Item's Source. Use real variables, not typed words.

3. After the repeat, Combine Text from the Repeat Results using New Lines, and Set Variable "Steps".

4. Find Health Samples where Type is Weight and Start Date is in the last 365 days. Do not group the results.

5. Repeat with each item in those weight samples:
   a. Format Date: the Repeat Item's Start Date, custom format yyyy-MM-dd.
   b. Text: the Formatted Date variable, a | character, the Repeat Item's Value.

6. After the repeat, Combine Text from the Repeat Results using New Lines, and Set Variable "Weights".

7. Get Contents of URL:
   - URL: PASTE_URL_HERE
   - Method: POST
   - Headers: "apikey" set to PASTE_PUBLIC_KEY_HERE, and "Content-Type" set to "application/json"
   - Request Body: JSON with three text fields:
       "p_key" set to PASTE_SYNC_KEY_HERE
       "p_steps" set to the Steps variable
       "p_weights" set to the Weights variable

8. Show Notification with the Contents of URL as the body.

3 · Run it every morning

  1. Shortcuts › Automation › + › Alarm › Is Stopped (or Charger › Is Disconnected).
  2. Choose Run Immediately, then pick kmwo sync.

iPhone only lets Shortcuts read Health while the phone is unlocked, so a morning trigger works better than a set time overnight. Each run re-sends the last 10 days, so a missed morning catches up later.

If something’s off

  • “Invalid API key”: the apikey header and p_key are swapped. The header gets the sb_publishable_ key; p_key gets your sync key.
  • “unknown sync key”: the key in p_key was replaced or mistyped. Make a new one above and paste it in.
  • step_samples is 0: the step Text line has typed words instead of variable tags. Rebuild it as described in step 2.
  • Steps about double Health’s: Find Health Samples for Steps has Group By set to Day. Set it to None.

Good to know

  • Synced steps and weigh-ins replace that day’s values.
  • Steps from your iPhone and Apple Watch are combined the way Health does it, so they aren’t counted twice.
  • The oldest day in each sync is left alone, since a “last 10 days” window starts partway through it. So steps_days is usually 10.
  • Shortcuts can’t read workouts. Add walks, runs and other workouts from the day page.
